# 공유 랭킹 설치 (구글 시트 + Apps Script) — 약 5분

링크만 있으면 **누구나**(로그인 없이, 닉네임으로) 같은 랭킹에 점수를 올릴 수 있게 합니다.
랭킹 데이터는 **본인 구글 드라이브의 시트 한 장**에 저장됩니다 (닉네임 · 점수 · 판 수 · 정답 수만, 개인정보 · 환자 정보 없음).

## 📱 휴대폰만 있을 때 (Chrome)
구글 시트 **앱**에는 Apps Script 메뉴가 없어서 **Chrome 브라우저**로 합니다. 시트를 따로 만들 필요는 없습니다 (스크립트가 'EKG 랭킹' 시트를 스스로 만듦).
1. 코드 복사: 휴대폰에서 `github.com/chokim90/ekg-trainer-play/blob/main/ranking-server/Code.gs` 를 열고 오른쪽 위 **복사 아이콘(Copy raw file)** 누르기
2. Chrome 으로 `script.google.com` 접속 → 메뉴 ⋮ → **데스크톱 사이트** 체크 → 구글 로그인
3. **새 프로젝트** → 편집기의 기존 코드를 길게 눌러 모두 선택 · 삭제 → 붙여넣기 → 💾 저장
4. 위쪽 함수 목록에서 **setup** 선택 → **실행** → 권한 검토 → 계정 선택 → **고급 → (프로젝트)로 이동 → 허용**
   (내 드라이브에 'EKG 랭킹' 시트가 생깁니다)
5. **배포 → 새 배포** → 유형 **웹 앱** → 실행: **나**, 액세스: **모든 사용자** → 배포 → 나온 **웹 앱 URL** 복사
6. URL 을 Claude 에게 보내기

화면이 작아 버튼이 잘 안 보이면 Chrome 메뉴에서 화면을 축소하거나 가로로 돌려 보세요. 가능하면 PC 가 훨씬 편합니다.

## 💻 PC 에서

## 1. 시트 만들기
1. 구글 드라이브 → **새로 만들기 → Google 스프레드시트** (이름 예: `EKG 랭킹`)
2. 메뉴 **확장 프로그램 → Apps Script**

## 2. 코드 붙여넣기
1. 열린 편집기의 `Code.gs` 내용을 **모두 지우고**, 이 폴더의 [`Code.gs`](Code.gs) 내용을 통째로 붙여넣기
2. 💾 저장 (Ctrl+S)

## 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**
2. ⚙ 유형 선택 → **웹 앱**
3. 설정
   - 설명: `EKG 랭킹`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** → **액세스 승인** → 본인 구글 계정 선택
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음) → 허용**
     (본인이 만든 스크립트가 본인 시트에 쓰는 권한을 묻는 것입니다)
5. 나온 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 을 복사

## 4. 게임에 연결
복사한 URL 을 Claude 에게 보내 주세요. 또는 직접:
`src/config/leaderboard.js` 의 `sheetUrl: ''` 에 붙여넣고 `npm run build`.

확인: URL 을 브라우저 주소창에 열면 `{"ok":true,"service":"ekg-trainer-leaderboard"}` 가 보이면 정상입니다.

## 관리
- **이상한 기록 지우기**: 시트 `scores` 에서 그 줄을 삭제
- **랭킹 초기화**: 제목 줄(1행)만 남기고 모두 삭제
- **코드를 고친 뒤**: 배포 → **배포 관리** → ✏ 편집 → 버전 **새 버전** → 배포 (URL 은 그대로)

## 알아둘 점
- 로그인이 없어서 점수 조작이나 남의 닉네임 사용을 완전히 막을 수는 없습니다 (같은 닉네임도 허용). 다만 다른 사람의 기록에 점수를 더하는 것은 막혀 있습니다 — 각 브라우저가 가진 비밀 토큰이 필요하고, 시트에는 토큰의 해시만 저장됩니다.
- 한 번에 올릴 수 있는 점수에 상한(60,000)이 있고, 수식으로 해석될 수 있는 닉네임은 정리됩니다.
- 브라우저 데이터를 지우면 새 플레이어로 시작합니다 (이전 기록은 시트에 남음).
