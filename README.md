# EKG 리듬 트레이너 (플레이 주소용)

EKG 리듬 판독 → 맥박 확인 → 가이드라인 대처를 반복 학습하는 교육용 게임입니다.

- 플레이: GitHub Pages 주소 (Settings → Pages 에서 `main` / `(root)` 로 켜면 `https://chokim90.github.io/ekg-trainer-play/`)
- 이 저장소에는 빌드된 `index.html` 한 파일만 있습니다. 원본 코드는 별도 저장소에서 관리하며, 수정은 그쪽에서 빌드해 여기에 덮어씁니다.
- 휴대폰에서는 브라우저 메뉴 → **홈 화면에 추가** 로 앱처럼 쓸 수 있습니다.
- 교육용 보조 도구입니다. 실제 처치는 기관 프로토콜과 최신 가이드라인 원문을 따르세요.
